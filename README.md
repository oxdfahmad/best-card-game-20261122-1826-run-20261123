Three Winds — an original 1-v-1 lane card duel of Gale, Bloom & Tide. Call wardens into three lanes, ride the wind Surge, and take Mistral's life to zero. Runs offline in a desktop browser from static files, played with mouse and keyboard.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` from any static server. `?shot=title|table|win|loss&seed=7` stages a screenshot scene.
